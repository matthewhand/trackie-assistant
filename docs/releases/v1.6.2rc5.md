# Trackie Assistant 1.6.2rc5 — local candidate

This candidate is not published. The public release remains v1.6.2rc2.

Uploaded video assets may use a different asset UUID from the song. A narrow
new source variant accepts the explicitly published official video only when
the same structural own-clip record binds its matching upload source to that
song. Hosts, paths, query cardinality and public visibility are checked. Media
URLs are never guessed. React Flight text records, including lyrics, cannot
supply clip objects or source bindings.

Public uploads use the existing verified-producer and staged additions-only
publication path. Audio packets are retained when extracting AAC audio, and
temporary video is discarded. Existing recordings are skipped before lookup.

Encoded player streams without an accessible plain fallback still require
a Suno-provided audio download in this version. Failed sources now log the clip UUID and
HTTP status without exposing URL queries; the missing recording remains eligible
for a later check. The UI schedule and existing library paths are preserved.
