# Trackie Assistant 1.6.2rc4 — local candidate

This candidate is not published. The public release remains v1.6.2rc2.

Public profile sync now follows the anonymous cursor-based feed used by Suno's
View all playlists screen, with bounded pagination, explicit profile identity,
and no cookies, authentication or redirects. An interrupted or capped listing
is reported as incomplete and retried on the next check.

Mixed playlists retain their verified public songs while excluding unavailable,
non-public, visibility-ambiguous and unsupported clips. All rows still count
toward the provider's complete membership total. Negative visibility evidence
applies across the profile and its playlists for the run.

Existing music is reused by clip UUID. This update does not rename, retag,
replace, rotate or delete it. A running backend must finish its active sync
before installing the update. Scheduling remains editable in the Sync UI;
changing the interval does not interrupt an active run.
