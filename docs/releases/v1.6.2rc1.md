# Trackie Assistant 1.6.2rc1 — Linux preview

Archive public Suno tracks from explicit playlists, songs or profiles, with
producer attribution verified from each clip's own page. Use the CLI, local
web UI/API or Home Assistant add-on.

## Included

- Trackie Assistant branding and Trackie Dacks README banner.
- The Python distribution is named `trackie-assistant`; commands `suno-dl`,
  `suno-webui` and `suno-recommend` remain compatible.
- Missing tracks are reused by clip identity, preventing duplicate downloads.
- Published MP4 can serve as a temporary audio source. Extraction preserves
  audio packets; only M4A audio and requested artwork are retained.
- Separate and embedded cover images, with a still-image fallback when needed.
- Playback pacing, audit records, staged publication and recovery guards.
- Queue counts, indicative saved-size estimates and destination free space.
- Maintained, digest-pinned Wolfi container base, Python 3.13 and FFmpeg 9.

## Installation and upgrade

Install the release wheel with the `tags` extra in a dedicated Python 3.13
environment; FFmpeg/ffprobe are also required. From source, use
`pip install -e ".[tags]"`. The optional `browser` extra provides profile browser
fallback. Container images include the needed runtime components.

For an existing standalone environment, stop its processes and uninstall the
old `suno-download-cli` distribution before installing `trackie-assistant`.
Do not install both distributions into the same environment. Existing music
is not renamed, retagged, removed or moved by a package upgrade.

Add the repository to Home Assistant's app store and select Trackie Assistant,
or use the bundled add-on folder for a local installation. No sources are
selected and sync-on-start is off by default. A repository install
has a different HA ID from `local_suno_dl`. Do not start a second writer against
a library whose current sync is still running.

## Preview scope and limits

- Supported writes: Linux, Python 3.13, new M4A recordings and requested sidecars.
  Container/add-on validation covers AMD64. ARM is not advertised by this preview.
- Full-profile playlist discovery can be incomplete. The app reports this;
  use explicit playlist URLs when exact coverage matters.
- Existing indexed files are reused unchanged. Older filename/artist corrections
  require the separate reviewed offline migration with all writers stopped.
- Automatic repair, force replacement, rotation, retained video, sidecar-free
  output and non-M4A output remain guarded. Windows/macOS archive writes are
  outside this release.
- Size figures estimate saved audio/artwork. Temporary video traffic and working
  space are additional; missing durations use an explicit assumption.

## Release validation

Prepared from the reviewed clean snapshot with fresh public Git history.
Public preparation performs no production sync or deployment. Build receipts,
image identities, checksums and scanner dispositions accompany the release
bundle. No PyPI publication or automatic deployment is configured.
