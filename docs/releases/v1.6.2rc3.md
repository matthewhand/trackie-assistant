# Trackie Assistant 1.6.2rc3 — local scheduling candidate

This candidate is being qualified locally. The public GitHub release remains rc2.

- Editable, persistent scheduling in the Sync tab; default six hours.
- Scheduled and manual checks share one run manager and playback pacing.
- Public playlists are revalidated each check; existing clip IDs are reused.
- Pause stops future checks and leaves an active download running.
- HAOS can act exclusively as an ingress client for a pinned HTTPS backend.
- No automatic file replacement, retagging, retention of video, or deletion.

Existing-library migrations remain separate, reviewed offline operations.
