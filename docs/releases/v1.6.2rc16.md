# Trackie Assistant 1.6.2rc16

- **Live Songs catalogue.** Standalone Trackie and the Home Assistant card display
  50 songs per page. Search, genre filters and sorting apply across the archive.
- **Safe Retry all cancellation on Linux.** Completed tracks stay counted.
  Unfinished tracks remain eligible for retry, and cancelling during download or
  tagging clears their staged files before publication.
- **Sync controls.** Schedule automatic syncs, manage skipped tracks, retry one
  track or the failed queue, and see the last Retry all result after a restart.
  Public playlist discovery now handles more playlist entries.

## Home Assistant

Standalone Trackie uses the live archive automatically. Set `ingress_app` on
the Home Assistant card to the Trackie add-on slug to use its authenticated
ingress connection. The backend can read an existing genre taxonomy from
`SUNO_GENRES_URL`. The archive sidecars supply the song inventory.

## Preview scope

Use Python 3.13 or newer on Linux. The Home Assistant add-on targets AMD64.
Sync reuses existing recordings by clip ID. See the
[offline producer migration](https://github.com/matthewhand/trackie-assistant/blob/v1.6.2rc16/docs/producer-migration.md)
for older filenames and artist tags.
