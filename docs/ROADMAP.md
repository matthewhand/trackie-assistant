# Roadmap

## Current delivery: Linux

CT107 is the authoritative music store. the Linux development host is the development host.
The current release and migration target Linux standalone CLI/web/API and the
HAOS add-on. Windows support is outside this delivery's acceptance criteria.

Priorities: finish the active sync without interruption; verify each clip's
producer; safely migrate older filenames and artist tags; complete Linux
integration, packaging and release acceptance.

## Future, unscheduled: Windows archive writes

Integrated crash-safe Windows publication/recovery is an aspirational roadmap
item. It is not a blocker for Linux, CT107, HAOS, or the producer migration.
Keep unsupported Windows archive writes disabled. Do not spend development or
review time on this item unless the user explicitly reopens it.

User direction, 2026-11-03: keep Windows work out of the current critical path
and routine progress updates. Report current Linux work and actual blockers.
